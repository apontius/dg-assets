# Disappointing Grace — Asset Repository

Static assets for [DisappointingGrace.com](https://www.disappointinggrace.com), hosted via GitHub Pages.

## Folder Structure

| Folder | Purpose |
|--------|---------|
| `audio/` | Audio clips served via GitHub Pages (permanent URLs, no expiration) |
| `blocks/` | Version-controlled backups of every MailerLite custom HTML block |
| `press/` | Press kit — cover images, headshot, one-sheet, media bio |
| `social/` | Social media assets — quote cards, story templates, ad creatives |

## GitHub Pages

Audio and press files are served at:

```
https://apontius.github.io/dg-assets/<folder>/<filename>
```

For example:
```
https://apontius.github.io/dg-assets/audio/dg-sample.mp3
```
