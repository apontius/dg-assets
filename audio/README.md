# Audio Assets

Audio clips for the Disappointing Grace website, hosted permanently via GitHub Pages.

## Usage

After pushing a file here, reference it on the site as:

```
https://apontius.github.io/dg-assets/audio/<filename>
```

Replace the BookFunnel signed URL in the site's `<audio>` tag `src` attribute with this permanent URL.
