# Social Media Assets

Graphics and templates for Disappointing Grace social media promotion.

## Contents

- Quote cards for Instagram/Facebook
- Story templates
- Ad creatives
- Launch countdown graphics

## Design Palette

| Token | Hex | Usage |
|-------|-----|-------|
| Deep green | `#1a3a3a` | Primary background |
| Dark green | `#243f3f` | Card backgrounds |
| Gold | `#c8963e` | Accents, borders, CTAs |
| Sand | `#f5f0e8` | Light backgrounds |
| Warm white | `#faf8f4` | Page background |
| Text dark | `#2a2a2a` | Headings |
| Text body | `#3d3d3d` | Body copy |
| Text muted | `#7a7a7a` | Attributions, captions |

## Fonts

- Headings: Georgia / serif
- Body: -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif
